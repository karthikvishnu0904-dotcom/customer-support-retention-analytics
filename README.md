# Customer Support & Retention Analytics

## Project Overview
An independent Data Analytics portfolio project designed to analyze customer support operations, customer satisfaction, and retention performance using a simulated dataset of 5,000 customer interactions from 2025.

## Tools & Technologies
- MySQL – Data analysis and SQL querying
- Microsoft Excel – Data exploration and analysis
- Python – Data analysis
- Power BI / Tableau – Dashboard development planning

## Business Objectives
1. Evaluate overall customer support performance.
2. Analyze monthly interaction and resolution trends.
3. Compare Phone, Chat, and Email channel performance.
4. Evaluate agent performance using customer satisfaction scores.
5. Identify issue types associated with repeat customer contacts.
6. Analyze customer interaction frequency and retention.
7. Generate actionable operational recommendations.

## Key Performance Indicators
- Total Customer Interactions
- Resolution Rate
- Customer Retention Rate
- Repeat Contact Rate
- Average Customer Satisfaction (CSAT)
- Average Handling Time
- Average Waiting Time

## Dataset Information
The dataset contains 15 columns covering interaction dates, customer IDs, agents, support channels, issue types, handling time, waiting time, resolution, retention, repeat contacts, and CSAT scores.

**Note:** All customer records are fictional and generated for educational and portfolio purposes. They do not represent actual company or customer data.
